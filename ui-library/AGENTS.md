# Reply library

Read the repository root AGENTS.md when this directory ships inside a checkout, then [AGENT_GUIDE.md](AGENT_GUIDE.md).

This directory is the ui-library part of the t3-html-replies repository. A personal install can also keep it at ~/.codex/templates/t3-ui-library, with the same files.

Use the CLI for replies. For edits, use the shared source modules; generated HTML is output.
Keep demos local and illustrative. Preserve unrelated files and existing task authority.
Run `node build.mjs`, `node verify.mjs`, then browser audits for changed layouts.
